# Parity pitch

One self-contained HTML file. Fonts, data and screenshots are inside it, so it runs offline.

    open commodity/presentation/parity-pitch.html

Controls: → / Space / click to go on, ← back, F full screen, N speaker notes.
On scene 1, click one of the four contracts to record the room's guess before pressing →.
On scene 15, S toggles the logo's signal state.
Pari, the mascot, narrates every step from the empty strip under the slides. It steps onto the stage only into empty space:
the title logo, the scale on the 'gap or gold' scene and beside the live logo, which it pushes. Click it to say hi; M hides it.

Every number comes from dashboard/data.json and clean/gold_futures.csv (MCX closing prices, 25 Sep 2026).
